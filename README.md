# Keyboard Beat Lab

一个本地浏览器键盘音乐游戏原型，包含分离的游玩界面和谱面编辑器。

## 功能

- 默认 `4K`，普通轨道可在 `1-10K` 之间切换。
- 普通轨道映射到键盘 `Q-P` 的横向区域，每条轨道可绑定多个物理键。
- `Space` 是独立大键轨道，显示宽度至少为 3 个普通轨道。
- 游玩界面底部只有一行无字母键位映射，音符接近或按键触发时高亮。
- 编辑器支持本地导入音频、粗略 BPM 识别、手动修正 BPM、自动创建小节线、规则优先自动写谱。
- 谱面可导出/导入 JSON。

## 运行

```bash
npm install
npm run dev
```

然后打开 Vite 输出的本地地址。

## 首版边界

- 自动写谱以 BPM 网格、轨道数、密度和难度为主，音频分析只做粗略辅助。
- 谱面首版只实现点击音符，长按音符数据字段已预留。
- 应用完全在浏览器本地运行，不上传音频。
